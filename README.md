## Overview

A cinematic, interactive 3D WebGL portfolio built with **Three.js**, **vanilla JavaScript**, and **responsive CSS**. The experience showcases production-grade full-stack architectures, high-throughput point-of-sale platforms, and artificial intelligence engineering across an interactive 3D camera timeline.

## Tech Stack

- **Core & Backend**: Python (FastAPI, Django), C++ (OpenMP), Node.js, Express, RESTful APIs
- **Frontend & 3D**: Three.js, WebGL, Next.js (App Router), React.js, Flutter, Tailwind CSS
- **Databases & DevOps**: PostgreSQL, SQLite, MongoDB, Firebase Firestore, Docker, Git

## Local Setup

```bash
# Clone the repository
git clone https://github.com/taha-qazi/Portfolio.git

# Navigate into the project folder
cd Portfolio

# Start local server
python serve.py
```

Visit `http://localhost:8000` in your browser.
