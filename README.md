## ??? Architectural Overview

A continuous, single-camera WebGL scroll journey engineered with **Three.js**, **vanilla JavaScript**, and **responsive CSS**. The portfolio takes the viewer through an 11-layer progression of production software systems, enterprise internships, capstone artificial intelligence research, and commercial software studio ventures.

- **Pre-baked 3D Particle Portrait**: Over 22,000 Float32 vertices dynamically assembled via custom mathematical easing functions with zero runtime image-parsing latency.
- **Dynamic 3D Scenes**: Procedural Three.js wireframes, glowing server racks, hospital map planes, neural try-on meshes, and rotating transaction engines.
- **Audio Scored Experience**: Integrated ambient soundtrack (*'Adrift'* by Scott Buckley) with responsive equalizer visualization and audio range-request support.
- **Fully Responsive**: Calibrated for high-DPI desktop screens, laptops, and mobile devices (iOS & Android).
